# Salon Booking Platform

A production-grade microservices-based salon booking system built with Spring Boot, React, and Docker. Features include customer booking flows, salon owner dashboards, admin panels, secure authentication with OAuth2 & Keycloak, online payments (Stripe & Razorpay), real-time notifications via WebSockets, and a complete reviews & ratings system.

**Architecture**: API Gateway → 9 Independent Microservices with asynchronous communication via RabbitMQ, service discovery through Eureka, and centralized authentication.

**Tech Stack**: Spring Boot, Spring Cloud, React, Redux Toolkit, Tailwind CSS, MySQL, RabbitMQ,AWS, Docker & Docker Compose.

Perfect for building portfolio-worthy projects that showcase real-world microservices architecture patterns used by companies like Netflix and Amazon.
